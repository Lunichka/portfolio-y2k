# КВАК, ГДЕ МОИ ВЕЩИ?! — концептуальный спецпроект

Запуск: открой `index.html` двойным кликом (сервер и установка не нужны).

## Структура
- `index.html`, `css/style.css`, `js/game.js` — вся игра
- `assets/scene.png` — твоя сцена (извлечена из старого прототипа)
- `assets/frog.png` — главная жаба, вырезана из f3dccfe4…jpeg (оригинал не тронут)
- `assets/fire/` — обрезанные кадры огня; `assets/props/receipt.svg` — твой чек (Asset 2.svg)
- `assets/props/ticket-avia.svg`, `ticket-cinema.svg`, `card-bank.svg` — ВРЕМЕННЫЕ ЗАГЛУШКИ
- `assets/fonts/` — Dela Gothic One, Onest и IBM Plex Mono (локально, без внешних запросов)

## Как заменить заглушку своим рисунком
В `js/game.js` в массиве `ITEMS` поменяй `src`, а также `x, y, w, ar, rot` (координаты в пикселях сцены 1024×559).
Область клика считается автоматически по размеру предмета.

## Оживление (v5)
- **Моргание** — `assets/frog-eyes-closed.png` (слой «закрытые глаза» из PSD, выровнен по `frog.png`), включается в `js/game.js` → `scheduleBlink()`.

  Движение: `@keyframes foot-scratch` в `css/style.css` (3,2 с), повтор через 10–20 с — `scheduleScratch()`.
- **Если из scene.png убрать слой «НОГИ» (AI):** переэкспортируй сцену в тех же пропорциях (1024×559 или 2048×1118),
  положи вместо `assets/scene.png` и в `js/game.js` поставь `LEGS_IN_SCENE = false` — обе ноги тогда рисуются из PSD, заплатка отключается.
- **Огонь** — `#stage-fire`: у каждого языка свои период/амплитуда/дрейф (`initFlames()`); рост от игрового таймера — `updateFire()` (уровень = `state.elapsed / 60 с`).
