# LEYLA OS 2.0 — портфолио

Статичный сайт без зависимостей и сборщика для самого сайта: HTML + CSS + JS.
Node нужен только для одной команды, которая пересобирает страницы кейсов.

## Запуск локально
```
cd leyla-site
python3 -m http.server 8000      # → http://localhost:8000
```
Через `file://` сайт тоже откроется, но браузер не даст «заморозить» GIF в режиме «Отдых для глаз» — они просто спрячутся.

## Публикация
Любой статический хостинг (Netlify, Vercel, GitHub Pages, Cloudflare Pages): залить содержимое папки `leyla-site/`.
У каждого кейса свой настоящий файл — `work/<slug>.html`, поэтому прямой заход, обновление страницы и ссылка
из резюме работают без 404. После публикации впиши адрес в `data/site.js → SITE_URL` и запусти сборку —
появятся `canonical` и `og:image`, а код кнопки 88×31 заполнится сам.

## Структура
| Путь | Что это |
|---|---|
| `index.html`, `styles.css`, `app.js` | рабочий стол LEYLA OS: загрузка, окна, архив проектов, гостевая, кнопка 88×31 |
| `css/theme.css` | общие токены и элементы для обоих режимов (шрифты, кнопки, окна, переключатель режима) |
| `css/case.css`, `js/case.js` | страницы кейсов |
| `js/mode.js` | режим Глиттер / Отдых для глаз: хранится в `localStorage`, общий для всех страниц |
| `data/site.js` | SITE_URL, EMAIL, ссылки |
| `data/projects.js` | **все проекты** — единственный источник данных для архива и кейсов |
| `work/*.html` | страницы кейсов (генерируются, руками не править) |
| `tools/build.mjs` | генератор кейсов |
| `tools/portrait_layers.py` | пересборка слоёв портрета (глиттер-ноутбук и контур) |
| `play/kvak/` | играбельная копия «Квак, где мои вещи?!» (без .git и shots) |
| `play/orchestra-1703/` | играбельная копия теста Orchestra 1703 (картинки PNG → WebP, исправлены charset/viewport и путь к шрифту Despair Display) |
| `assets/portrait/` | портрет: `suit.webp` (база) + `laptop-glitter.webp` + `outline-glitter.webp` |
| `assets/projects/<slug>/` | медиа проектов |
| `assets/fonts/` | шрифты локально, с кириллицей (Tiny5, Pixelify Sans, Marck Script, шрифты проектов) |

## Скрытые проекты
Проекты с `hidden: true` в `data/projects.js` не публикуются (сейчас так скрыты Paradai, «Читает Артем Назаров», Club Puer). Удали строку и запусти сборку — проект вернётся.

## Две папки с работами
- **ПРОЕКТЫ.DIR** — спецпроекты и игры (основное портфолио под вакансию).
- **ДРУГИЕ_РАБОТЫ.DIR** — сайты и UI для клиентов. Проект попадает сюда, если в `data/projects.js` у него стоит `shelf: 'other'`.
  Убери строку — и он вернётся в основной архив. Навигация «предыдущий / следующий» на кейсах работает внутри своей папки.

## Как добавить или поправить проект
1. Открой `data/projects.js`, скопируй объект проекта, поменяй поля (описание полей — в начале файла).
2. Положи медиа в `assets/projects/<slug>/` и пропиши пути.
3. `node tools/build.mjs` — пересоберёт `work/*.html` и выведет список того, чего ещё не хватает.

Для видео можно поставить `soon: true` — тогда до появления файла показывается аккуратная плашка «СКОРО». Пока файла нет, на месте картинки или видео стоит заметная заглушка «ФАЙЛ НЕ НАЙДЕН» с путём,
куда его положить. Положила файл → запустила сборку → заглушка исчезла.
Поля `todo` выводятся на странице кейса жёлтой плашкой «ЧЕРНОВИК» — удали пункт, когда текст готов.

## Два режима
- **Глиттер** (по умолчанию): глиттер-обои, бегущая строка, искры и шлейф курсора, GIF, ретро-курсоры,
  портрет с розовым глиттер-ноутбуком и глиттер-контуром, курсив и Comic Sans в декоративных местах.
- **Отдых для глаз**: окна Windows 95/98, спокойное небо с пиксельными облаками, без анимации и блёсток,
  GIF заморожены, портрет с серебристым ноутбуком.

Переключатель — в таскбаре («Режим: ✦ Глиттер | ☁ Отдых для глаз»), на телефоне — кнопка «ОТДЫХ: ВКЛ/ВЫКЛ»,
на страницах кейсов — в верхней панели. Смена режима не закрывает окна, не сбрасывает фильтр и гостевую.
`prefers-reduced-motion` выключает движение автоматически; в меню «Пуск» можно включить его вручную.

## Портрет
Исходник не редактируется. Глиттер-версия — это два отдельных слоя поверх того же фото:
крышка ноутбука из присланного референса, перспективно натянутая на серебристую крышку (пальцы
вырезаны по цвету и остаются поверх), и контур из блёсток. Полноразмерные слои и оригиналы лежат в
`leyla-site-sources/`. Пересобрать:
```
python3 tools/portrait_layers.py ../leyla-site-sources/originals/portrait-suit-cutout.png \
  ../leyla-site-sources/originals/pink-glitter-laptop-reference.jpg ../leyla-site-sources/portrait-layers-fullres
```
Углы крышки — в начале скрипта (`DST_LID`), если захочешь подвинуть.

## Шрифт Fiolex Girls
Если он установлен у посетителя — используется сам. Чтобы он был у всех, положи `FiolexGirls.woff2`
в `assets/fonts/` и раскомментируй `@font-face` в начале `css/theme.css`.

## Гостевая
Сервера нет: запись посетителя хранится только в его браузере (`localStorage`), демо-записи помечены «ДЕМО».
