# Orchestra 1703 — Music Personality Quiz

An interactive music quiz that invites users to explore the world of classical music through personality, playful storytelling, and bold visual design.

Answer 7 questions to discover which of 7 composer archetypes matches your personality.

## About the Project

Created for Orchestra 1703, this project reimagines classical music discovery as an engaging digital experience. Instead of presenting music history as a list of facts, the quiz uses personality-driven questions and illustrated results to make the subject more approachable and memorable.

The experience combines editorial-style typography, collage-inspired visuals, playful interface details, and animated transitions to create a distinctive visual identity.

## Features

- **7 interactive questions** — a short, personality-driven quiz.
- **7 composer archetypes** — discover your musical match.
- **Personalized results** — a final character profile based on your answers.
- **Illustrated storytelling** — custom visual scenes and composer-inspired artwork.
- **Animated transitions** — visual feedback between screens.
- **Responsive layout** — an experience designed for desktop and mobile screens.
- **Reduced-motion support** — respects users who prefer less animation.

## Design Direction

The visual language combines the cultural character of classical music with a playful, contemporary web aesthetic.

Key elements include:

- Bold typography and expressive compositions.
- A warm palette of deep green, coral, mustard, and cream.
- Layered illustrations, outlines, and graphic shadows.
- Motion and interaction used to reinforce the experience rather than distract from it.

## Tech Stack

- HTML5
- CSS3

- React

## Run Locally

1. Clone or download this repository.
2. Open the project folder in your code editor.
3. Start a local development server, for example with the VS Code Live Server extension.
4. Open the quiz page in your browser.

A local server is recommended for a reliable development experience.

## Project Goals

- Make classical music feel more accessible through interaction.
- Turn a simple quiz into a cohesive visual experience.
- Combine visual design, UX thinking, storytelling, and front-end implementation.
